<Timeline>
    <Era id="first-machine" period="Age 10 - The beginning" title="First machine, first lines of code">
        At age 10 I got my first computer, and with it a book about the visual programming language
        Scratch. That was my first touch point with software engineering.

        After building some things in it, it annoyed me that I could not run these games
        standalone. That itch spiked my interest in *real software development*. My first text
        based programming language was Python. It taught me all the fundamentals and gave me a
        basic introduction into this new world.

        Soon I explored the ecosystem more and more, but I wanted to make games, which got me into
        Unity and C#. I soon realized C# was too complex for me, so I learned it by creating basic
        desktop applications. In parallel I got invested into web development and created my first
        frontend, without really understanding what I actually did.

        <TagRow label="Tools" items="Scratch, Python, Unity, C#, HTML, CSS" />
    </Era>
