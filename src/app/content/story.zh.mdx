# 我的故事

<Lead>一段关于代码、开发者工具与构建软件的个人叙述。</Lead>

我一直想发明新东西，解决问题，做些有意思的东西。许多项目从未发布，有一些留在了这里。

<TokenMark />

<Timeline>
    <Era id="pre-era" period="前传" title="发明家的雏形">
        在一切成真之前，我把自己的构想和发明画在一个小本子上，梦想着发明出某种革命性的东西。如今我才明白，这才是最重要的部分：*去梦想不可能的事，并保持创造力*。
    </Era>

    <Era id="first-machine" period="10 岁 - 起点" title="第一台电脑，第一行代码">
        10 岁那年，我有了第一台电脑，还有一本讲可视化编程语言 [Scratch](https://scratch.mit.edu) 的书。那是我第一次接触软件工程。

        用它做了些东西之后，我开始不满：这些游戏没法脱离 Scratch 独立运行。正是这份不满，点燃了我对*专业软件开发*的兴趣。我学的第一门文本编程语言是 [Python](https://www.python.org)，它教会了我所有基础，也带我初步走进了这个新世界。

        很快，我对这个生态的探索越来越深，但我想做游戏，于是接触了 [Unity](https://unity.com) 和 [C#](https://dotnet.microsoft.com/en-us/languages/csharp)。我很快发现 C# 对当时的我来说太复杂，于是通过编写简单的桌面应用来学习它，主要靠阅读 GitHub 上其他项目的源代码。与此同时，我迷上了 Web 开发，做出了自己的第一个前端，尽管并不真正明白自己在做什么。

        <TagRow label="工具" items="Scratch, Python, Unity, C#, HTML, CSS" />
    </Era>

    <Era id="java" period="十二三岁" title="Java、Minecraft 插件与 Discord 机器人">
        在第一批脚本和第一批客户之间，是一段*为做而做*的时期。

        [Minecraft](https://www.minecraft.net) 服务器插件教会了我 [Java](https://dev.java)，而且是用最难的方式：配置文件、堆栈跟踪，还有一天重启上百次的服务器。

        差不多同一时期，我开始写 [Discord](https://discord.com) 机器人：有些有用，大多数毫无意义，但每一个都很好玩。重点从来不是机器人本身，而是我可以在傍晚做出点什么，朋友们当晚就能用上。

        那些早期实验有一部分仍在 [GitHub](https://github.com) 上。这些卡片上的图标是我自己设计的，在 AI 设计工具出现之前亲手绘制。

    <Era id="first-clients" period="少年时代" title="第一批客户，第一批课程，第一次登台">
        我一步步开始真正理解事物的运作方式，也接到了最初几份有偿的专业咨询工作，为朋友和熟人提供简单的前端支持。

        我第一次体验了大学：在 [OpenCampus](https://edu.opencampus.sh) 修读游戏开发、JavaScript、市场营销和创业课程，拿到了正式证书和我的第一批 [ECTS](https://en.wikipedia.org/wiki/European_Credit_Transfer_and_Accumulation_System) 学分。我也投身创业圈，参加了 [Waterkant](https://waterkant.sh) 等活动，完成了*第一次路演和演讲*。

        在代码之外，我也在学习如何打动观众：我制作的 3D Minecraft 动画，先用 [Mine-Imator](https://www.mineimator.com)，后来用 [Blender](https://www.blender.org)，让我的 TikTok 涨到了 9.7 万粉丝。这个账号至今仍在，虽已沉寂，但仍属于我。

        随着毕业考试结束，中学生涯画上了句号。那段时间我主要零星接些自由职业的活，运用过去几年积累的经验，同时对网络安全的兴趣与日俱增。那时的两个项目至今仍在运行。

        [VailNote](https://vailnote.com) 也诞生于这段过渡期：开发始于我中学的最后几年，大约一年后公开发布，至今仍在积极开发中。
